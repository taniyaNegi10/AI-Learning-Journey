## 🔗 Prompt Chaining

Learned how the output of one LLM call can be used as input for another LLM call.

```text
Prompt 1
    ↓
LLM Response
    ↓

    ↓
Final Response
```

## ⚡ Streaming

Implemented streaming to receive AI-generated responses incrementally instead of waiting for the complete response.

```text
User Question
      ↓
LLM Starts Generating
      ↓
Response Appears Gradually
```

---

## 🔍 Introduction to RAG

Learned the basic concept behind **Retrieval-Augmented Generation (RAG)**.

RAG allows an LLM to use external information as context before generating an answer.

```text
User Question
      ↓
Retrieve Relevant Information
      ↓
Provide Context to LLM
      ↓
Generate Better Answer
```

---

## 🧮 Embeddings & Semantic Similarity

Learned how text can be converted into numerical vector representations called **embeddings**.

I also implemented **cosine similarity** to compare the semantic similarity between sentences.

```text
Text
    ↓
Embedding Model
    ↓
Vector Representation
    ↓
Cosine Similarity
    ↓
Similarity Score
```

---

## 🚀 First RAG System

Built my first basic RAG system by combining:

- Embeddings
- Cosine Similarity
- Semantic Search
- Information Retrieval
- LLMs

### RAG Pipeline

```text
Knowledge Base
      ↓
Create Document Embeddings
      ↓
User Question
      ↓
Create Question Embedding
      ↓
Cosine Similarity
      ↓
Retrieve Relevant Information
      ↓
Add Context to Prompt
      ↓
LLM
      ↓
Generate Final Answer
```

This project helped me understand how the main components of a RAG system work together.
